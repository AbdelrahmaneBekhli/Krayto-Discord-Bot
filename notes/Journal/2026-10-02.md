## Learned

- **The defer bug was the real find.** Not a crash — intermittent and load-dependent, so it would read as "the bot is flaky" rather than a bug with a location. Anything that awaits before responding needs `defer()`. → [[Interaction Timing]]
- **Verified the API instead of assuming it.** `data.get("question") or data.get("dare")` looked reasonable; `/api/dare` actually returns its text under `question` too, so half that line was dead. An unknown endpoint also returns **400**, not 404. → [[Truth or Dare API]]
- **Omitting help metadata doesn't hide a command** — it sends it to the `Other` fallback instead, which is how a private command ended up listed publicly. Hiding requires an explicit `show_in_help=False`. → [[Help Registry]]
- **`interaction_check` beats a helper method.** The old `guard()` worked but was opt-in per button.
